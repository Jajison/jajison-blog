# 认识会动手的 AI：什么时候用 Codex、WorkBuddy 或普通聊天

**这一篇做成什么**：选一个任务，判断只需对话，还是需要 AI 实际处理文件，再写清工作范围。

普通对话可以给建议、解释和草稿。有工具能力的 AI 还可能读取指定材料、生成文件、修改项目或运行程序。常见行话把这种按目标选择行动的系统叫 Agent；Harness 指围绕它安排工具、运行和控制的配套。日常使用先关心它能碰哪些东西，以及怎样核对结果。

## 从你要的结果选择

| 我的任务 | 先试哪条路 | 我需要会检查什么 |
| --- | --- | --- |
| 改一封邮件、解释一段文字 | 普通对话 | 事实、语气、是否改变原意 |
| 查一项时效信息 | 带搜索的对话或研究工具 | 来源、日期、适用条件 |
| 整理本地资料、生成报告 | WorkBuddy 等桌面文件助手 | 输入与输出文件、数字与内容 |
| 做自己的小网页、修改项目 | Codex 等编程助手 | 运行效果、文件变化、旧功能 |
| 经常在编辑器里写代码 | Cursor 等编辑器中的 Agent | 改动、实际测试、项目上下文 |

这张表是起点。很多产品能力有重叠，最终以自己的小任务能否完成判断。[Codex](https://learn.chatgpt.com/docs/codex/cli)、[Cursor](https://cursor.com/docs/agent/overview)、[Claude Code](https://code.claude.com/docs/en/overview)的官方说明介绍了读取、修改项目和运行命令的用途；[WorkBuddy 权限说明](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Permission-Modes)说明了工作目录与文件操作范围。

## 第一次先准备独立练习目录

在“文档”中建一个“AI 练习”文件夹，只放本次需要的副本。选择该目录作为工具的工作位置，再让它列出看到了什么。

不要把“打开文件夹”与“上传整个电脑”混为一谈。不同产品如何访问、处理与保存资料，要核对当前入口与说明。只有聊天输入时，也可先复制必要文字完成任务。

## 把授权范围写进任务

~~~text
请在这个练习目录完成任务。
目标：[具体成果]
输入：[指定材料]
可以做：读取输入，生成新的结果文件，检查结果。
原材料保留，输出放到 result 文件夹。
本次只生成草稿，不向别人发送，不发布到外部网站。
完成后说明：产生了哪些文件、实际检查了什么、还有哪些未确认。
~~~

这让工具知道你要它动手到哪一步。如果确实需要发布或发送，再把对象、内容与范围明确写出来。

## 四个状态不要混淆

| 工具反馈 | 你应该看什么 |
| --- | --- |
| “我准备生成” | 这是计划，尚无成品 |
| “已运行” | 有实际动作，但业务结果还要检查 |
| “已生成文件” | 找到文件，打开核对 |
| “已经检查通过” | 看它检查的项目与实际结果 |

例如报告生成成功，但金额算错，仍不能交付。程序能启动，但按钮没效果，也没有完成小工具任务。

## 卡住时先定位一件事

工具找不到文件，先核对目录；生成内容遗漏，先核对材料是否读全；不会运行，要求说明在哪个应用打开、结果应长什么样；同一错误反复出现，保存当前结果，换一个更小的任务。

第一次不需要同时安装多个连接器或复杂插件。需要处理云盘、邮件或其他应用时，再确认工具支持什么以及访问范围。

## 练习：选择与说明

从“会议记录变行动清单”和“做一个待办网页”中选一个。分别写出输入、输出、允许动作、检查方法，再进入对应教程。

**完成标准**：能够解释选这类工具的理由；知道工作目录；能检查实际成果，而不是只看完成消息。
