# 先认识你的电脑：Windows 和 Mac

你照着教程找按钮，别人说“打开 Finder”，你的电脑却只有“文件资源管理器”；别人按 Command，你的键盘上没有这个键。先别怀疑自己，可能你们用的是不同系统。

这一篇只做几件会反复用到的事：知道自己用什么电脑，找到文件，建立练习目录，选对应用下载包。用 AI 不需要先换电脑，也不需要先学终端。

## 电脑、系统、应用，各指什么

电脑是设备；操作系统管理文件、窗口和设备；应用用来完成具体工作。Windows 和 macOS 是操作系统，浏览器、Word、AI 桌面助手是应用。

Mac 是苹果的电脑，常用系统叫 macOS。其他品牌电脑可能使用 Windows，也可能使用 Linux。不能只凭外观或品牌猜系统。

你在浏览器里打开 AI 网站，通常仍在使用在线服务；应用安装在本机也可能连接远端。界面在哪里和内容在哪里处理，是不同问题。

## 先看自己的系统信息

Windows 可以从开始菜单进入设置，找到“系统”里的“关于”或“系统信息”。Mac 可以从左上角苹果菜单打开“关于本机”。记录系统版本、处理器或芯片和内存；名称随系统语言与版本可能不同。[Apple 查看系统信息](https://support.apple.com/guide/mac-help/get-system-information-about-your-mac-syspr35536/mac)

下载时看到 x64、ARM64、Apple silicon、Intel 或 Universal，回这张信息卡核对。Apple M 系列对应 Apple silicon；Intel Mac 选相应 Intel 版本。Windows 的 x64 与 ARM64 也不是同一安装包。

这次只记录，不需要研究芯片性能排名。在线 AI 的普通文字练习，不要求先购买独立显卡。

## 两种系统，先记这几项差别

| 要做的事 | Windows | Mac |
| --- | --- | --- |
| 找电脑里的文件 | 文件资源管理器，常用 Win+E | Finder，常见为 Dock 上的笑脸图标 |
| 复制、粘贴、保存 | Ctrl+C、Ctrl+V、Ctrl+S | Command+C、Command+V、Command+S |
| 新建文件夹 | 空白处右键 → 新建 → 文件夹 | Finder 的文件菜单 → 新建文件夹 |
| 重命名 | 选中文件，常用 F2 | 选中文件，常用 Return |
| 解压 ZIP | 右键 → 全部解压 | 双击 ZIP，找到解压后的文件夹 |
| 删除后的常见位置 | 回收站 | 废纸篓 |

“+”表示同时按键，不是输入加号。右键通常是鼠标右键；Mac 触控板可用双指点按，或按住 Control 再点击。不同应用的快捷键可能不同，找不到时看应用菜单。

## 跟着建一个“AI 练习”文件夹

打开文件管理器，进入“文档”，新建“AI 练习”。再在里面建“原始材料”和“结果”两个文件夹。

回浏览器，下载 [练习会议记录](../downloads/workshop/daily-practice/meeting.txt)。在下载列表找到它，选择“在文件夹中显示”或类似入口，把副本放进“原始材料”。

现在关闭文件窗口，再打开一次，自己找到那份记录。能重新找到，比临时打开过更重要。第一次使用 WorkBuddy 或 Codex 时，也会需要明确的工作位置。

## 文件地址，像一条找东西的路线

“文档 → AI 练习 → 原始材料 → meeting.txt”，就是你找这份记录的路线。电脑里的完整写法叫路径；给 AI 说“在桌面那份材料”可能不够明确。

两个不同文件夹里的 meeting.txt，可能是两份独立文件。修改其中一份，不会当然改另一份。求助时说明文件位置，而不只说名字。

文件图标带云朵时，可能只有云端内容，尚未完整下载到本机。准备交给本地任务前，先确认能在本机打开。

## 看清扩展名，避免认错文件

文件名结尾的 .txt、.pdf、.xlsx，叫扩展名。系统可能默认隐藏它们。Windows 可在文件资源管理器的查看设置里找“文件扩展名”；Mac 可在 Finder 设置的高级页找“显示所有文件扩展名”。[Microsoft 说明](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/common-file-name-extensions-in-windows)、[Apple 说明](https://support.apple.com/guide/mac-help/mchlp2304/mac)

打开显示以后，看看文件实际是不是 meeting.txt，而不是 meeting.txt.txt。把后缀改成 .pdf 不会自动得到 PDF，需要对应软件真正转换或导出。

更多常见格式和上传过程，下一篇 [文件指南](../learn/03-files-and-formats.md)会带你练。

## 下载应用，和下载材料不一样

安装包是用来安装应用的；文档和图片是材料；ZIP 是压缩包。下载完成不代表应用已经安装，也不代表 ZIP 已解压。

从产品官网进入下载，选择自己的系统与芯片，核对最低系统要求。Windows 常见 .exe、.msi；Mac 常见 .dmg、.pkg。按官方安装说明操作，再实际打开应用。

遇到系统拦截时，先核对来源和官方帮助，不要直接关闭全系统保护。工作或学校管理的设备，按设备提供的安装流程处理。

## 常见卡点，其实可以具体说清楚

| 现象 | 先检查 |
| --- | --- |
| 下载后找不到 | 浏览器下载列表里的实际位置 |
| 打开的是旧内容 | 是否在另一个同名文件夹 |
| 应用安装不了 | 系统、芯片、版本与下载项是否匹配 |
| 压缩包内能看到文件，却不好编辑 | 先完整解压到普通文件夹 |
| 编辑后“原文件没变” | 是否改了副本，是否保存成功 |

可以给 AI 当前截图和一句具体目的，让它一次说明一个动作。截图里先移除账号、验证码和无关窗口。见 [截图求助](images-and-multimodal.md)。

<summary>以后做项目时，再认识 Linux、终端和硬件</summary>

Linux 是另一类操作系统，常见于服务器，也有桌面版。Mac 不是 Linux；它们有不少相似的 Unix 风格命令，但安装包和部分命令不同。

终端是输入文字指令的工具。Windows 可能用 PowerShell，Mac 常见 zsh。现在的文件与对话练习不要求开终端；需要运行项目时看 [工作环境](editor-and-environment.md)。终端里的 Control+C 常用于中断运行，并非普通复制动作。

RAM 是运行中的工作空间，硬盘是长期存文件的地方；硬盘剩余空间多不等于内存充足。只有要运行本地模型等任务时，再根据实际项目检查硬件要求。WSL、虚拟环境和模型部署都属于按需内容。
