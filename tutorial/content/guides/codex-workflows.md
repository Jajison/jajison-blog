# 把 Codex 用顺：修改、排错和重复任务

第一个网页能用了，新的想法随之而来：想只看未完成，想调一下布局，想让表格统计也省点事。一次把所有愿望发出去，可能得到很大的改动，你反而不知道哪里出了问题。

使用上的进阶，可以从把一项改动说清楚开始。我们继续上一篇的待办网页，再看读项目、修问题和做重复任务的办法。

## 先保存一个能回来的版本

复制当前可用文件，标明日期或版本。记录怎样打开、数据在哪里、主要功能哪些已经检查。

小练习用副本就能开始。想更方便地记录修改历史，再学 [GitHub 和版本管理](github-from-zero.md)。不用因为还不会 Git 就停在这里。

## 只增加一个筛选功能

~~~text
在现有待办网页增加“全部 / 仅未完成”筛选。
筛选只改变显示，不删除事项。
新增、勾选、刷新保存和导出继续正常。
默认导出完整清单，不只导出当前显示的部分。
先简要说明要改什么，再完成并检查。
~~~

任务里说清了一个容易误会的地方：画面隐藏和数据删除不同，当前显示与导出范围也不同。

完成后自己试：三条事项，勾选第二条；筛选未完成应显示两条；切回全部还是三条；刷新再看；导出仍应包含三条。旧功能没有丢，才算修改完成。

## 不会看代码，也能了解改了什么

请 Codex 用普通语言说明文件、原因和影响：

~~~text
请说明本次哪些文件改了、每项对应哪个用户操作。
把实际检查、尚未检查和已知限制分开。
不要只说“优化完成”。
~~~

桌面改动视图或代码审查入口可以辅助检查；具体使用当前界面。终端用户可按 [官方审查说明](https://learn.chatgpt.com/docs/code-review?surface=cli)了解相关入口。第一次不用为了读懂改动先掌握全部代码。

如果它只是换了实现，却没有说明筛选和保存的关系，继续问这个具体问题。你需要知道改动会影响什么，才能决定下一步检查哪里。

## 修问题，先让现象可以重复

“偶尔丢数据”太宽。改成“打开这个网址，新增三条，刷新后为空”，就有了明确过程。

~~~text
请先尝试复现，或说明为什么当前环境无法复现。
预期：[结果]
实际：[现象]
相关文件/网址：[位置]
保留其他正常功能，修好后用同样步骤验证。
~~~

无法复现时，补浏览器、打开方式、控制台提示或截图。不要让它同时重做所有功能。修完仍看原步骤，也检查紧邻的保存、筛选和导出有没有受影响。

## 下载一个项目，先问怎么用

GitHub 上的项目可能是源码，不是可以双击的安装包。先告诉 Codex：“我想用成品”“我想本机运行”或“我想修改”，这三种目的不同。

~~~text
请读这个目录，用普通话说明它做什么。
我的目的：在本机使用。
先给入口、需要准备的应用、运行方法、输入与结果位置。
区分读到的事实和未确认内容；先不修改文件。
~~~

对照实际 README 和文件确认。只有文件名，不能推断全部行为；项目运行要求还要查它自己的说明。

## 用重复任务推动一个小工具

例如每周核对费用，可以做“选择 CSV—确认字段—汇总已确认金额—导出”的本地工具。先用 [四条练习费用](../downloads/workshop/daily-practice/expenses.csv)，确认已确认金额 250 元。

再加一条已确认 30 元，结果应 280 元。试空文件、缺金额、重复编号等情况，让它明确提示，而不是悄悄填值。使用场景明确以后，再谈更多功能。

本机工具未必适合直接给别人使用。共享、部署和跨设备数据需要另行设计，见 [发布与检查](../learn/12-test-and-publish.md)。

## 留一份下次能读懂的说明

~~~text
工具用途：个人待办。
打开方式：[实际方法]
数据位置：当前浏览器，另可导出。
已有功能：新增、完成、筛选、保存、完整导出。
必查：三条新增，勾选，切换筛选，刷新，导出。
已知限制：[按实际情况]
下一步：[只写一项]
~~~

开发项目常用 AGENTS.md 记录长期工作约定。这次只需与项目相关的短规则：保留数据，修改后检查主要功能，说明未验证范围。不要堆一份很长、互相矛盾的规则。

## 任务卡、Skill 和插件，按需增加

重复同一套方法，先存任务卡。确实稳定好用，再按产品入口保存成 Skill；插件适合接入确实需要的外部工具与服务。[官方 Skills 与 Plugins](https://learn.chatgpt.com/docs/skills-and-plugins?surface=cli)

关键是知道它处理什么、需要哪些资源、结果在哪里。装得多不代表用得熟，能重复完成自己的任务才有意义。

**完成标准**：一项新功能可用，原有功能仍正常；保留修改前版本；有实际检查记录和下次可继续的说明。
