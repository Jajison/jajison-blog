# AI 工具地图：聊天、搜索、文件助手和会动手的 AI 怎么选

**这一篇做成什么**：根据任务挑工具，先试一个小样本，再决定是否继续使用或付费。

模型是生成和理解内容的核心；产品把模型、文件、搜索与其他功能组合起来。你使用的同一个产品可能包含多种能力，是否能用还取决于账号、地区、设备和版本。看名称无法确定这一项任务能否完成。

## 先问自己要拿到什么

| 想拿到的结果 | 需要的能力 | 适合先做的小测试 |
| --- | --- | --- |
| 一段解释、草稿、翻译 | 对话与文本处理 | 用一段公开材料改写成三种读者能理解的版本 |
| 有出处的时效信息 | 搜索或研究，并能打开来源 | 查一个发布日期明确的官方通知 |
| 基于现有材料的摘要 | 文件读取与资料问答 | 上传两页文本，问一条可人工核对的事实 |
| 可打开的表格、文档或演示 | 文件生成与格式处理 | 生成一页文件，下载后检查格式 |
| 新图片或图片修改 | 图像生成或编辑 | 明确尺寸、用途与保留元素后试一次 |
| 本地文件整理、小程序 | 文件操作或执行工具 | 在独立练习目录生成一个新文件 |
| 已有应用里的动作 | 连接器、应用授权 | 先查询一条允许读取的记录 |

能在聊天框输出表格文字，并不说明能交付 `.xlsx`；能读文件也不说明能访问电脑上所有目录。以小测试中的真实结果判断。

## 常见产品先这样认识

- **DeepSeek、豆包、ChatGPT、Gemini、Claude 等对话产品**：可以从文字解释、学习与内容工作入手，按实际账号提供的文件、搜索和生成入口继续使用。不要假定它们拥有完全相同的按钮。
- **Codex、Claude Code、Cursor 的 Agent**：偏向项目文件和开发任务，适合在目标明确时帮你理解项目、做小工具、修问题。要能找到结果并检查它。
- **WorkBuddy**：腾讯的桌面 AI 工作助手，可从文件、文档与日常任务开始。本站提供单独的上手路线。
- **你已有软件中的 AI 功能**：如果资料已经在办公软件里，先了解原软件是否能完成任务，能减少来回复制和下载。

这里描述用途，具体账号能用的能力仍应查看产品本身。有关接入外部应用，参考 [Gemini 官方连接应用说明](https://support.google.com/gemini/answer/13695044)；开发工具用途见 [Codex 官方介绍](https://learn.chatgpt.com/docs/codex/cli)、[Claude Code](https://code.claude.com/docs/en/overview)、[Cursor Agent](https://cursor.com/docs/agent/overview)。

## 还没有使用过任何产品时

可以从 [DeepSeek 官方入口](https://www.deepseek.com/)或 [豆包官方入口](https://www.doubao.com/)了解网页与应用方式，也可以使用自己已经能够访问的其他产品。按官方页面的账号提示进入，不需要为本站练习额外购买多个套餐。

第一次只做文字任务：打开新对话，把 [第一份行动清单](../learn/01-first-result.md)的任务卡复制到输入框，再点击发送。等到看到结果，复制到自己的笔记中核对。先走通这一步，再寻找上传、搜索或文件生成入口。

需要安装手机或电脑应用时，从产品官方页面进入下载路径，并核对设备版本。用同一份材料试一次之后，再判断它是否适合你的任务。

## 用“六项试用表”取代盲目排名

同一个任务、同一份材料，记录下面六项。先用已有或可用的工具，不必全部注册。

| 检查项 | 记录实际情况 |
| --- | --- |
| 输入 | 能否读懂我的中文、文件和图片？ |
| 结果 | 生成的是草稿、可下载文件，还是实际修改？ |
| 准确 | 有没有遗漏、编造数字、错误引用？ |
| 修改 | 第二轮能否按指定位置改，保留正确内容？ |
| 使用成本 | 我花了多久检查、重做和整理？ |
| 可带走 | 文件能否在常用软件打开，后续能否编辑？ |

“回答很长”“看起来漂亮”都只是观察。选择工具要看它能否让你的任务完成得更好。

## 当功能没有出现

先核对登录账号、设备和产品名称，再查看当前帮助说明。有些入口只在特定账号或版本出现；某个网页教程出现的菜单，不保证你的界面相同。

把缺口说出来：只有对话功能时可以先让 AI 给草稿或步骤；需要文件生成但当前工具做不到时，再换支持这一项的工具。不要反复要求一个没有权限读取文件的产品“继续找”。

## 练习：只比较一个用途

取同一段 300 字的公开通知，让手头工具输出“截止日期、对象、需要准备的材料、出处”。打开原文核对四项；再要求改成可以发给同事的 100 字提醒。记录第一次准确性和第二次修改质量。

**完成标准**：能说明选了哪种工具、为何适合当前任务，以及一个实际发现的限制。没有把广告宣传当成自己的实测结果。

<details>
<summary>自测：某工具能聊天、搜资料，是否就能替我整理电脑里的文件？</summary>

不一定。需要实际具备文件访问与操作功能，并获得相应范围。工具能做的事，应从界面、权限和真实小测试确认。
