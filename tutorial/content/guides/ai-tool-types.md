# 选你的第一款 AI 工具

认识了这么多工具，接下来最容易卡住的是选择：我是不是应该下载最热门的？免费版够不够？朋友说某款更好，我要不要换？

先把选择缩小。**你现在只需要一个能帮你完成当前任务的入口。** 这一篇以“把会议记录整理成清单”为例，带你做一次真正的试用。其他任务也可以照这个过程判断。

## 想清楚你要带走什么

同样叫“整理会议”，可能是三种不同需求。你只想看一份摘要，文字对话就可以开始；你要下载一份 Word 清单，需要文件生成；你要处理电脑里二十份记录，需要访问文件夹和批量处理。

先把结果写成一句话：“我想拿到一份能在 Word 里继续改的行动清单。”这比“我要最强的 AI”更能帮助选择。

| 你要的结果 | 先找哪项能力 | 第一次怎么试 |
| --- | --- | --- |
| 解释、草稿、翻译 | 文字对话 | 给一小段材料，要求改成自己的用途 |
| 当前信息和出处 | 搜索或研究 | 找一条能打开的官方通知 |
| 根据现有资料回答 | 文件读取 | 问一条自己能在原文定位的事实 |
| 文档、表格、演示文件 | 文件生成与导出 | 做一页，下载到常用软件打开 |
| 图片或图片修改 | 图像生成、编辑 | 给尺寸和用途，试一张小样 |
| 本地文件整理 | 文件访问与执行 | 在练习目录生成一个新文件 |
| 自己的小网页 | 项目文件与开发协助 | 做一个按钮，亲手点一次 |

能在聊天框显示表格，不等于交付了 Excel 文件。AI 说“已经保存”，也需要实际找到文件。这些区别在第一次试用时就能发现。

## 先用你已经能够访问的一个

没有用过任何产品，就从 [常用工具介绍](choose-an-ai-agent.md)的官方入口选一个。已经用过豆包、DeepSeek 或其他助手，就先用它，不必清空已有经验。

网页入口通常省去安装这一步；桌面入口适合需要电脑文件的任务；手机便于随手提问，但长表格和文件核对常常在电脑上更方便。使用体验不只是模型能力，也包括你找材料、保存和修改是否顺手。

功能有时只在特定设备、账号、地区或套餐出现。遇到教程里的按钮没有出现，先查看当前官方帮助；不要把账号限制误认为自己操作不好。

## 跟着试：用同一份记录做清单

打开 [练习会议记录](../downloads/workshop/daily-practice/meeting.txt)，选择全部相关文字，复制到新对话。先试最基础的文字任务：

~~~text
请把下面的虚构会议记录整理成行动清单。
列出任务、负责人、截止时间和原文依据。
未明确的负责人、日期写“待确认”。
“考虑增加线下场次”单独列为讨论想法，不写成已经确定。
[粘贴会议记录]
~~~

你要观察的第一件事不是排版，而是它有没有把“考虑”写成“决定”，有没有给缺日期的任务补一个日期。这份小材料就能让你发现真实限制。

第二轮，要求一个小修改：

~~~text
保留已经核对过的事实。
把每条任务缩短成一句话，并按“明确待办、需要确认、讨论想法”分组。
~~~

看它有没有只改你要求的部分。能生成第一版，却无法保留正确内容修改，也会给后续工作增加负担。

最后，如果你确实需要文件，再问：

~~~text
当前工具能否生成可下载的 Word 文件？
如果可以，请把这份已核对清单做成一页文档；
如果不支持，请给方便复制进 Word 的正文，不要声称已生成附件。
~~~

能下载就打开检查；不能下载也没关系，这次你得到了一个明确结论：它能帮你处理文字，但这项入口暂时不能完成你需要的文件交付。

## 用六个问题记录体验

| 问题 | 写具体观察，别只写“不错” |
| --- | --- |
| 材料进得去吗？ | 是粘贴、上传，还是无法读取？ |
| 事实对得上吗？ | 有没有遗漏、错日期、编造？ |
| 修改听得懂吗？ | 是否保留了已经正确的部分？ |
| 成品带得走吗？ | 文件能打开、能继续编辑吗？ |
| 我花了多少时间？ | 包括整理、等待、核对和修改 |
| 限制影响我吗？ | 哪项额度、格式或入口挡住了任务？ |

如果确实想比较第二个工具，就用**同一份材料、同一条要求、同一套检查**。一款试简单通知，另一款试复杂表格，不能公平比较。

也别把一次结果当作永久排名。更实用的结论是“我现在用它整理短记录比较顺手，生成文档时还要换入口”。

## 什么时候值得付费或换工具

你已反复完成任务，知道缺的是文件导出、使用额度或另一项具体功能，再查看购买页是否明确包含它。先做小测试，再决定。

如果不满只是“语气有点硬”，先试修改；如果工具根本读不到文件，换说法未必能解决。把能力缺口和表达问题分开，选择会轻松很多。费用、续费与资料处理见 [上传、费用和保存](privacy-and-cost.md)。

## 留下一张自己的选择卡

~~~text
我选的工具：
我要完成的任务：
已经试过的材料：
它能完成的部分：
需要我检查或换入口的部分：
下次什么时候再评估：
~~~

**完成标准**：完成一份小清单和一次修改，能说明为什么选它、还差什么。你的选择来自自己的使用，而不是一张排行榜。

<details>
<summary>自测：一个工具回答最长，就最适合我吗？</summary>

长度不代表准确，也不代表省事。要看它是否读到材料、完成用途、便于修改，成品能否保存，以及核对和重做花了多久。

</details>
