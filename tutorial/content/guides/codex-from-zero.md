# 第一次用 Codex，做一个自己的小网页

如果你有一个想法：“我想要一个只给自己用的待办清单”，普通聊天可以告诉你怎么写代码，但你可能还是不知道代码放在哪里、怎样运行。

Codex 可以围绕项目文件协助执行。你描述用途，它帮助生成和修改；你打开实际成果，看看操作是否符合需要。第一次不用做一个完整大网站，我们做一个可以添加、完成和导出的小待办网页。

## 它怎样帮你，哪些仍由你决定

你负责的是用途和判断：谁用、做什么、数据放哪里、怎样算完成。Codex 可以协助读文件、修改项目和运行工具，但“已经完成”的消息不能代替你检查实际使用。

我们这次只做本机练习，不要求注册 GitHub、安装整套开发工具或购买 API。账号是否可用、用量和平台支持，以当前官方入口为准。

## 先找到桌面入口

从 [官方桌面开始说明](https://learn.chatgpt.com/docs/app)进入下载与安装，按系统和芯片选择。当前官方文档以 ChatGPT 桌面应用为入口，说明了选择 ChatGPT 或 Codex 的方式；旧版本名称和菜单可能不同。

已有应用就先打开并核对登录账号，在相应产品选择里进入 Codex，创建任务或聊天，选择本地文件夹。找不到时查当前帮助，别照旧截图猜。

Codex 也有 [终端入口](https://learn.chatgpt.com/docs/codex/cli)。本篇先走桌面路线；终端不是这次练习的前提。

## 给待办网页一个家

在“文档”里新建“我的待办练习”，用应用打开这个目录。文件夹暂时空着也正常。

~~~text
我不懂编程，这是第一次练习。
请先说明当前工作文件夹和里面的文件。
我要做一个小网页，请告诉我结果将保存在哪。
先不要创建复杂项目或安装额外依赖。
~~~

对照文件管理器，确认位置正是你刚建的目录。工作文件夹就像这次任务的桌面：输入、成果和说明集中放在这里，后面更容易找。

## 用普通话描述第一版

~~~text
请在当前练习目录做一个个人待办网页，文件叫 todo.html。
中文界面，手机宽度也方便操作。
功能：新增文字待办、勾选完成、导出 JSON 清单。
刷新后保留事项；在页面明确说明仅在当前浏览器保存。
不需要登录、远程服务或外部依赖。
空文字不能新增；输入内容按普通文字显示。
完成后告诉我：文件在哪里，怎样打开，怎样停止预览。
请实际检查能检查的项目，未检查的列出来。
~~~

这里没用专业术语定义每个按钮，而是说清日常动作。JSON 是保存结构化内容的文本格式，这次只需要核对导出的事项和完成状态，不必背语法。

如果它准备引入很多额外功能，先回到这个小范围。账号、多人协作和跨设备同步都可以以后再讨论。

## 看它的过程，分清计划和成品

| 它说了什么 | 你现在得到了什么 |
| --- | --- |
| “准备创建网页” | 计划，还没有成果 |
| “生成了 todo.html” | 应该有一个实际文件，去找 |
| “启动了预览” | 需要完整网址和运行中的预览 |
| “检查通过” | 需要看检查了哪些项目 |

让它说明实际文件与打开方式。直接文件打开和本地预览网址可能是不同方法，按这份成果的说明使用，不用自己猜命令。

## 打开网页，做四次普通操作

找到 todo.html，不是 todo.html.txt；用浏览器按说明打开。如果给本地预览网址，复制完整网址并保持预览运行。用完按说明停止。

现在你来试：

1. 新增“买书、整理资料、写周报”，应看到三条。
2. 只勾选第二条，只有它处于完成状态。
3. 刷新页面，三条和对应状态仍在。
4. 导出清单，找到下载文件，确认三条都在、状态对应。

再输入空白，应该不能新增；输入`<b>练习</b>`，应作为普通文字显示，而不是被解释成页面标签。

这些检查是使用能力，不要求你看懂每行代码。Codex 的检查可以帮助发现问题，你的实际操作确认了它在当前环境里可用。

## 出问题，描述一个能重复的过程

~~~text
我打开的文件或网址：[具体位置]
浏览器：[名称]
操作：新增三条，勾选第二条，然后刷新。
预期：三条与完成状态保留。
实际：[具体现象或截图]
请定位这个问题，保留其他正常功能。
修好后说明改了什么，再给检查步骤。
~~~

按钮不响应、刷新丢内容、下载找不到，是不同问题。把最后一个动作说清楚，修复更有方向。

如果你在一个网址保存事项，又换另一个网址打开，数据可能不在同一来源下。浏览器保存不是自动跨设备同步，清除站点数据也可能移除它。需要可靠长期保存时保留导出文件。

## 留下第一版，再继续一个小变化

把可用文件复制到备份目录，保存一份使用说明。以后想改“只看未完成”，让它增加这一项，再重做原来四次操作。

不要一次加账号、共享、同步、提醒和主题。每次变化小一点，你能知道好在哪里、坏在哪里，也更容易恢复。

**完成标准**：成果和打开方式清楚；四项操作由你核对；知道数据与导出文件位置；能用具体反馈修一个问题。
