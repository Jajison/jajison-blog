# Codex 从零上手：不会写代码，也能做出第一个小网页

**这一篇做成什么**：让 Codex 做一个个人待办网页，自己检查它是否能用。先用桌面入口，无需先学一整套编程语言。

Codex 能围绕项目读取文件、修改内容并运行相应工具。它与提供代码文字的普通聊天不同：交付可能是工作目录中实际产生的文件。当前官方桌面说明提供选择文件夹与 Codex 的入口；应用名称与菜单可能随版本调整。[官方桌面开始说明](https://learn.chatgpt.com/docs/app)

## 第一步：找到正确入口

已有 Codex 应用时直接打开，核对登录账号。首次安装从官方文档的下载入口选择适合自己系统的版本。Windows 和 Mac 的安装包不同；芯片不清楚时先看 [操作系统指南](computer-and-os.md)。

桌面界面中选择项目或本地文件夹，然后进入 Codex 的任务入口。找不到入口时，检查当前产品、账号和官方帮助，不要凭旧截图猜按钮。

Codex 也提供终端入口；本篇不要求使用。已经习惯终端的读者可以看 [官方 CLI 指南](https://learn.chatgpt.com/docs/codex/cli)。

## 第二步：建一个练习文件夹

在文档中建“我的待办练习”。用应用打开这个文件夹。先发：

~~~text
这是我的第一个练习。我不懂编程。
请先说明你当前在哪个文件夹、里面有哪些文件。
告诉我生成的小网页会保存在什么位置。
~~~

目录为空也正常。确认工作位置与自己建立的目录一致，再继续。

## 第三步：用一张具体任务卡

~~~text
请在这个练习目录做一个个人待办网页。
第一版：新增文字待办、标记完成、导出 JSON 清单。
界面中文，手机上也容易操作。
保存到当前浏览器，并在页面说明仅此浏览器保存。
成果：一个 todo.html，无登录、无远程服务、无外部依赖。
空文字不能新增，用户输入按普通文字显示。
完成后告诉我怎样打开、怎样停止预览、文件在哪里。
请实际检查能检查的项目，未检查的明确列出。
~~~

JSON 是一种保存结构化内容的文本格式；这次只需要会打开导出的文件，看它是否包含三条记录和完成状态。

## 第四步：打开真正的文件

让 Codex 明确说明“在什么应用里、打开哪个文件或网址”。如果给本地预览网址，复制完整网址到浏览器，并保持相关预览运行；用完按工具说明停止。

如果给 `todo.html`，在文件管理器找到它，再按提供的运行方式打开。确认不是聊天里的代码预览，也不是名为 `todo.html.txt` 的文字文件。

## 第五步：你亲手检查四件事

1. 新增“买书、整理资料、写周报”三条，列表出现三条。
2. 只勾选第二条，完成状态对应正确。
3. 刷新页面，三条和完成状态保留。
4. 导出清单，打开文件，核对三条与状态。

再试一条空输入，应该被拒绝；试输入 `<b>练习</b>`，应显示普通文字。没有必要为了检验这个小工具先看懂每一行代码。

## 不正常时怎样反馈

~~~text
我打开的是：[具体文件或网址]
我做了：[哪个操作]
预期：[应该发生什么]
实际：[现象或截图]
请定位这一项问题，保留其他已经正常的功能。
修好后说明修改了什么，再给我检查步骤。
~~~

不要只说“不能用”。按钮无反应、刷新丢数据、下载找不到，是不同问题。数据仅保存在当前浏览器与站点来源；换设备、清站点数据或换预览地址，都需要重新核对保存情况。

## 保存第一版，再加一件事

把可用版本复制到备份目录。第二次只加“筛选未完成”，仍重做四项检查。想学习更可靠的版本记录时，再读 [GitHub 入门](github-from-zero.md)。

**完成标准**：文件与打开方式清楚；四项主要功能经自己核对；知道数据在哪里；能用具体反馈让 AI 修一项问题。
