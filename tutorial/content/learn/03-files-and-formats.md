# 文件怎么找、怎么给 AI、怎么保存

AI 说“请上传材料”，你点了选择文件，却不知道哪一个才是刚下载的；它给了结果，你又不确定保存到了哪里。文件操作不熟悉，会让一次简单任务变得很费劲。

我们用一份小会议记录走一遍。先不讲代码，只把材料和成果安顿好。

## 一份文件，先知道名字、格式和位置

把文件当作一份东西，文件夹当作存放位置。meeting.txt 是名字，.txt 提示它是普通文字，路径说明它放在哪里。

同名文件可以在不同文件夹存在。电脑“找不到文件”，常常是找的目录与实际位置不同，并不是内容消失了。

扩展名只是线索，真正格式取决于内容。把文本重命名为 .pdf，不会完成格式转换。显示扩展名的方法见 [Windows 与 Mac](../guides/computer-and-os.md)。

## 常见材料，用什么打开

| 格式 | 你可以先怎样理解 | 常见用途 |
| --- | --- | --- |
| .txt | 普通文字，排版很少 | 原始记录、短笔记 |
| .docx | 可编辑文档 | 正文、报告、简历 |
| .pdf | 固定页面的文档 | 阅读、分享、打印 |
| .xlsx | 工作簿，可有多张表和公式 | 费用、统计、清单 |
| .csv | 用文字存行列数据 | 简单表格、导出数据 |
| .jpg / .png | 图片 | 截图、照片、插图 |
| .zip | 压缩包，里面可能有多个文件 | 下载一套材料 |
| .md | 带简单排版标记的文字 | 笔记、说明、报告 |

PDF 中可能是可选中文字，也可能是扫描图片。工具能打开文件，不一定能准确读取每一页。内容比较复杂时，要核对它实际读到了什么。

## 下载一份你找得到的材料

打开 [虚构会议记录](../downloads/workshop/daily-practice/meeting.txt)。如果浏览器直接显示文字，可以全选相关内容复制；若下载了文件，到下载列表选择“在文件夹中显示”。

在“文档”里建立“会议练习”，再建“原始材料”和“结果”。把材料副本放进原始材料，打开确认六条记录都在。

只留下载目录容易混进同名文件。给本次任务一个家，下次就能回到同一个位置。

## 粘贴和上传，选一个先走通

**粘贴**：从原文复制相关文字，放到 AI 输入框的要求之后。适合短材料，也便于自己看到提供了什么。

**上传**：点附件或文件入口，进入刚建的目录，选会议记录。等到界面显示已添加，再发要求。

不要只说“看我的电脑里的记录”。普通对话未必能访问本机文件。支持本地工作目录的助手，则按它的实际入口选择目录。

~~~text
请先列出你实际读到的会议事项。
如果有部分文件或内容没读到，请说明。
暂时不要起草报告，我先核对材料。
~~~

文件名显示在界面，并不证明正文完整读到了。抽问一条具体事实，比如“赵宁的期限是哪一天”，再回原文核对。

## 有问题时，先保留原件

中文乱码可能是文本编码问题。本站材料使用 UTF-8；在软件里选择相应导入编码，不要反复覆盖唯一原件。

文件太大或不支持，先看当前工具的格式、大小和账号限制。可以在允许的情况下导出为支持格式，或只提供目标页的文字。不要把复杂表格全部截图，就假定没有丢失公式与结构。

PDF 没有可选文字时，可能需要文字识别。见 [图片与提取](../guides/images-and-multimodal.md)。识别以后再查数字和行列。

## 结果有三种常见样子

| 你拿到了什么 | 怎么保存 | 还要查什么 |
| --- | --- | --- |
| 聊天里的正文 | 复制进笔记或文档软件，保存 | 换行、内容是否完整 |
| 可下载附件 | 下载并移到“结果”文件夹 | 文件能否打开，格式是否正确 |
| 本地助手生成的文件 | 在工作目录找到实际文件 | 是否为最新版本，是否覆盖原件 |

页面预览是一种查看方式，不一定就是保存。AI 只写“已完成”时，请它给实际文件名、位置或下载入口；当前工具不支持生成就先保存正文。

## 再打开一次，才算保存成功

给文件一个容易辨认的名字，例如“2026-10-20-会议清单”。关闭编辑窗口，再从文件夹里打开，检查内容还在。

两份结果不要都叫“最终最终版”。日期、任务和版本号能帮你区分。重要原材料保留，不用在唯一原件上反复试。

小网页里的浏览器保存、聊天历史和文档文件是不同位置。备份或换设备时，分别确认能否导出与恢复。

HTML 常用来描述网页；JSON 按字段保存结构化数据；.py 是 Python 程序。它们不要求你现在掌握语法。

## 现在完成一次材料到结果

把会议记录交给 AI，整理为行动清单，保存在“结果”。检查原记录保留、清单有三项明确待办，线下场次仍标讨论中，通知负责人和发送时间仍待确认。

**完成标准**：材料和结果都能重新找到并打开；知道用了粘贴、上传还是目录访问；没有把改后缀当作格式转换。
