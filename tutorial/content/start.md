# 第一次来，从这里开始

这里面向不懂计算机、但希望了解 AI 并用得更好的人。你不需要先学编程或模型公式。**先选一件自己想改善的事，完成一份能检查的成果，再补遇到的知识。**

[到首页填写学习画像](index.md#learning-advisor)，选择电脑基础、熟悉的操作、学习目的与每周时间。建议在浏览器中生成，不上传答案。它是自报起点参考；已经会做的内容可以完成自测后跳过。

## 把一次使用完整走通

1. 准备一份少量、相关、可以使用的材料。
2. 说明目的、读者和希望得到的结果。
3. 先做第一版，核对事实和遗漏。
4. 按具体问题修改，再检查文件或实际效果。
5. 保存成品、任务卡和一条修改经验。

“更专业”可以具体表达为：谁看、需要哪项事实、哪些内容不确定、文件怎样打开。做到这些通常比把提示词写得很长更有用。

## 每周时间不多，怎样安排

第一次只做十分钟能核对的小任务。用五条记录写一份总结，用四条费用练统计，用一张截图理解一个按钮。已经能完成后，再换自己的允许使用材料。

每周不到两小时，可以先做一篇里的练习；两到五小时，可以换材料重做一次；时间更多，再加异常情况，例如资料缺日期、表格有空值或文件读不到。篇数与阅读时长不是能力考试。

## 下载后不用先运行代码

[完整练习包](downloads/ai-workshop.zip)解压后，打开 `daily-practice` 文件夹。通知、会议记录、费用表可以直接在普通编辑器或办公软件查看，用于本轮日常用法。虚构素材有明确标注，避免把私人工作资料作为首次练习。

练习包也保留 Python、网页、检索等内容，读者按需要选用。Python 部分有独立运行说明，日常资料练习不依赖它。
