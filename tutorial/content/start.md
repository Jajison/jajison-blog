# 你不需要先成为程序员

这里的“熟练”有三个可观察的标准：能说清任务；能检查结果；能把有效的方法重复使用。会不会背命令不是标准。

## 路线 A：先把日常工作做好

读 [01](learn/01-first-result.md)、[02](learn/02-context-and-checks.md)、[03](learn/03-files-and-formats.md)，做 [项目一](projects/01-weekly-report.md)。只需浏览器和你能使用的 AI 对话工具。

完成标志：AI 给你的每个数字、日期和待办，都能回到原文核对。做到这里，已经可以改善会议整理、报告初稿和资料归纳。

## 路线 B：让重复工作自动完成

接着读 [04–08](learn/04-workspace.md)，做 [项目二](projects/02-work-tool.md)。从安装 Python 到读懂报错，只围绕一份工作记录汇总脚本展开。

完成标志：把输入换成下周的数据，工具仍能输出正确结果；数据有问题时，能给出明确提示。

## 路线 C：开发一个自己的小工具

在 B 的基础上读 [09–12](learn/09-web-and-api.md)。用 AI 和配套代码做待办网页，理解本地预览、浏览器保存和公开发布的区别。

完成标志：新增、勾选、刷新、导出都能按约定工作；知道清理浏览器数据会影响本地记录。

## 路线 D：理解 AI，搭建资料助手

读 [13–20](learn/13-nlp.md)，做 [项目三](projects/03-document-assistant.md)。这是按需进阶，不是开始使用 AI 的门槛。

完成标志：知道什么时候只需提示词、什么时候该检索资料，什么时候值得引入 Agent；能写下停止条件并用样例评价效果。

## 每篇怎么读

1. 先看“这一课做成什么”，判断它是否解决当前问题。
2. 跟着例子完成一次，观察实际输出。
3. 做一个小改动，确认自己掌握的是方法。
4. 用“完成标准”核对，再看文末自测答案。

每篇时间是阅读与第一次练习的粗略估计；首次安装软件、处理网络问题可能更久，不必把它当作进度考核。

## 本教程的最小边界

暂时不要求你学习算法题、微积分推导、完整 Linux 运维、模型训练、GPU 配置或复杂多智能体框架。只在它们影响实际选择时解释一点背景。

完成路线后，找一件每周重复、输入稳定、结果容易核对的工作，作为第一个真实项目。范围越小，越容易判断 AI 到底帮了多少忙。
