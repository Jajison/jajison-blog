# 定位与内容边界

对外名称：**Jajison · 把 AI 用起来**。一句话承诺：从第一份可用成果，到自己的小工具，补齐运用 AI 所需的最少知识。

## 目标读者与教学策略

读者会用浏览器和办公软件，但可能不知道当前目录、文件扩展名、终端、API。正文不能用“很简单”“只需配置一下环境”跳过关键步骤。先给一个能理解的输入和输出，再解释它背后的技术。

20 篇分为五阶段，每阶段四篇。01–03 能独立带来办公收益；04–12 解决脚本与开发；13–20 是可选的原理与 Agent 进阶。不能把后半段设成前半段的先修课。

## 最小集合的取舍

| 纳入 | 深度上限 | 暂不纳入 |
| --- | --- | --- |
| 提示词、资料、结果检查 | 目标、输入、约束、验收；一份任务卡 | 提示词流派大全、玄学咒语 |
| 文件、终端、Linux | 路径、目录、进程、权限概念；少量命令 | 内核、服务器调优、权限位计算 |
| Shell、Python | 读懂、运行、改一个参数；输入输出 | 算法题、面向对象体系、包发布 |
| Git、网页、API | 保存版本、小网页、请求响应、密钥放置 | 分布式架构、Kubernetes、完整后端体系 |
| NLP、Transformer、LLM | 文本表示、注意力、训练与使用的区别 | 反向传播推导、手写 Transformer、模型榜单 |
| RAG、Agent、MCP、Harness | 判断何时需要；搭出能验收的流程 | 向量索引调优、多 Agent 编排大全 |

“最小”指减少先修知识和工具选择，不等于略去新手必需的运行步骤、错误提示和完成标准。

## 统一示例

虚构的协作小组：小林、小周、小陈。虚构工作记录、项目进度与活动规则。不引入作者原有求职知识库、个人项目架构、业务数据或经历。

正文不假设读者购买了某一订阅。对话练习使用可用的任意工具；程序练习可以离线运行。API 只教授概念；资料助手采用手动 AI 回答与离线检索串联，明确区分演示与完整 Agent。
