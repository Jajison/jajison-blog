## 环境与范围

macOS，Node.js 24.20.0、Python 3.9.6。Quartz 生产构建以与 GitHub Pages 相同的 `/jajison-blog/` 子路径预览。浏览器实测使用 Codex 内置浏览器，桌面 1440 × 1000、手机 390 × 844 视口；视口模拟不等于实际手机或 Windows 真机测试。本轮未提交、推送、公开部署或调用真实模型 API。

## 真实练习与数值核对

- 报告：4 条记录、3 条完成、120 分钟总耗时、90 分钟完成耗时；改变输入后统计相应变化。覆盖损坏 JSON、BOM、空输入、字段/类型错误、重复编号、负数、带空格路径、预览不写入与拒绝覆盖。
- Shell：实际执行行数统计、循环、文件缺失及空目录分支。当前环境有 sh，本轮未跳过 Shell 检查。
- SQLite：实际运行内存库及文件库，验证筛选、分组、参数化查询、约束失败、事务回滚及拒绝覆盖。
- HTTP：本机临时端口启动真实服务器，客户端请求健康检查、任务读取与摘要，核对数据及常见错误。客户端明确绕开系统代理访问本机。
- 检索：运行逐行关键词检索及 7 个带行号标签的评价用例，核对 Recall、MRR、无答案及输入错误；与项目三的 10 个人工模型验收情境分开。
- 受控循环：运行真实只读检索子进程，核对结果、停止原因、调用预算、时间截止，以及注入文本不会变成命令。
- 正文片段：在临时副本验证 Git 暂存/提交/差异流程、Python、NLP、SQL；核对 BPE、梯度、softmax、注意力、LoRA、DPO、缓存容量小例子。

## 仍未覆盖的环境与边界

- Windows PowerShell / WSL 按系统编写并参考官方文档，未在 Windows 真机运行；未验证真实远程 GitHub 登录、PR 合并或 Pages 部署。
- 内置浏览器未返回下载事件，但本轮已通过实际文件内容及重新导入验证进度导出。仍保留同一快照生成的可复制 JSON 备份，供浏览器限制下载时使用。
- 未用浏览器模拟 localStorage 禁用、写满及损坏；数据格式分支有自动测试，存储异常路径经过代码检查。
- 公式标签保留 LaTeX 源码，未用真实读屏软件验证自然语言数学朗读；未覆盖所有浏览器及辅助技术组合。
- 工具循环超时测试验证截止行为，未单独覆盖运行中子进程被终止；HTTP 正文读取超时也未单独实测。
- 无真实模型训练、GPU 性能测试、向量数据库、多模态服务或付费模型调用。检索及固定策略循环成功不能报告为完整 LLM、RAG 或自主 Agent 已通过质量验证。
- 关键技术结论参考官方文档或原论文；未逐一检查所有外部链接未来是否仍可访问，没有虚构模型通过率。

## 复查方式

在仓库根目录运行：

~~~sh
python3 tutorial/tools/check_content.py
python3 tutorial/tools/check_examples.py
npm test
npm run build
npm run check:blog
python3 scripts/preview_blog.py --port 8765
~~~

练习源码变更后先运行 `python3 tutorial/tools/package_workshop.py`；图示生成器变更后先运行 `python3 tutorial/tools/make_diagrams.py`。浏览器验收前重新构建并刷新预览。
