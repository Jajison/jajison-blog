# 视觉与阅读设计

## 参考观察

2026-09-11 查看了 Walter's Tech Blog 首页和知识库路线页。可借鉴：深色底与明亮主按钮、短主标题、清晰的精选阅读入口、独立学习路线、自测反馈、搜索入口。参考站面向工程读者，主题数量和数学先修不适合直接沿用。

本教程以“看懂、敢做、做完”为中心。保留简洁的技术感，减少粒子背景、打字机文字和术语密度。首页先展示读者能完成的任务，再展示课程概念。

## 页面结构

- 顶部：站点名、从这里开始、课程、练习、查词；右侧搜索与主题切换。
- 首页：一句承诺 + 第 1 课按钮 + 按任务选择入口 + 五阶段路线。
- 文章：阶段与预计时间 → 标题与一句收益 → 正文 → 练习 → 完成标准 → 自测答案 → 下一篇。
- 桌面文章页：正文 720px 左右；右侧目录 200px 左右。窄屏折叠目录，正文不再留侧栏。
- 正文最大行宽约 34–40 个汉字；长表格和代码单独横向滚动，不能撑宽整页。

## 风格基准

| 元素 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 | #F7F8FC | #11151D |
| 内容表面 | #FFFFFF | #1A2230 |
| 主文字 | #1B2537 | #EDF2FA |
| 次文字 | #526078 | #B7C3D6 |
| 主色 | #315BD6 | #8BAEFF |
| 实操强调色 | #137A65 | #77D8BF |

正文使用系统中文字体，18px、行高 1.85；移动端最低 17px。标题 30–40px，限制单页标题层级在三级。代码 14–15px，按钮触摸区域至少 44px。交互元素提供可见键盘焦点；对比度上线前按 WCAG AA 实测。

文章图片采用原创 SVG，固定 viewBox、中文标签，背景与文字自带颜色，保证浅深主题均可辨认。图必须有替代文本，重要信息同时在正文中解释。装饰与示意图不得伪装成真实模型输出。

手机上为复杂图示提供“查看原图”入口，可缩放查看；不能仅把 860px 宽的整图缩成一张小缩略图来承载关键信息。学习路线仍同时保留正文列表，流程图同时保留文字步骤。

## 三类信息提示

1. “动手做”：只放马上可操作的步骤。
2. “完成标准”：可观察的结果，避免“已经掌握”。
3. “卡住了”：给出症状、最可能原因与一个最小排查动作。

不把每段都做成卡片，不用大量 emoji 代替标题。图文错落服务于阅读，不追求满屏装饰。

## 首版交互边界

网页实现时优先：全文搜索、文章内目录、代码复制、上一课/下一课、深浅色、移动端阅读。自测先用原生 details 展开答案，不做登录。阅读进度若实现，只存设备本地，并向读者说明换浏览器不会同步。

暂缓：评论系统、账号、访问统计、付费体系、打字机动画、复杂知识图谱。当前内容包并未实现上述网站交互。

## 上线时的视觉验收

在 390px 和 1440px 宽度检查首页、Shell 课、Transformer 课、项目页：无整页横向溢出；命令与输出易区分；图中中文可读；长表格能滑动；键盘能访问主要入口；浅深主题均可读；关闭动画不会影响信息。
